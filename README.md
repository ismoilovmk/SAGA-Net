# SAGA-Net

Official repository of our paper on video-based recognition of aggression among school children.

> The paper is currently under review. The code, pretrained models, and the SAGA dataset will be released soon.

## Repository Structure

```
SAGA-Net/
├── data/
│   └── samples/    example clips (physical, verbal, group)
├── models/         model code and weights (after acceptance)
├── utils/          data loading and evaluation scripts (after acceptance)
└── README.md
```

## Samples

[`data/samples`](data/samples) contains five example clips (5 s each) for each class. All faces are blurred and the audio is removed.
